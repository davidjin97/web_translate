02

翻译服务

设置默认服务；翻译时可在弹窗临时选择。

ⓘ

无需 API Key，即可尝试网页翻译。此服务使用非官方免 Key 接口，无稳定性承诺；需要可访问 Google 的网络。长期使用建议选择官方 API。

需在 Google Cloud 启用 Cloud Translation API v2 和计费。请限制 Key 仅用于该 API。

弹窗、右键菜单和快捷键默认使用此 API 及它的默认模型。弹窗临时选择不会修改这里的默认值。

自定义名称，方便在翻译弹窗中区分服务商。

填写 Base URL 或完整 /chat/completions 地址；支持 HTTP / HTTPS、兼容服务和本地模型。

⚠

HTTP 不加密传输，API Key 和待翻译文字可能被网络中的其他人读取或篡改。仅建议用于可信内网或自建服务，公网服务建议使用 HTTPS。

填写此 API 实际可用的模型 ID，最多 50 个。删除一行即可移除模型。

将此 API 设为默认或在弹窗切换到此 API 时，优先选中此模型。

测试连接会测试当前正在编辑的 API 和它的默认模型；所有配置在点击“保存设置”后才会保存。

◇

Key 只存储在本机插件中，网页无法读取。译文请求会发送给你配置的 API 服务商，并使用你的账户额度。公开分发时建议通过自建后端管理凭证。

配置后，可用一句示例检查服务连接。

◇

你的阅读，由你掌控。

只有你主动开启翻译后，网页文字才会发往所选服务。我们不上传阅读记录，不收集统计数据。Key 不云同步，翻译缓存只在内存中保留最多 15 分钟。动态新增内容会在已开启的页面继续翻译。

快捷键 Alt + T / Mac ⌥ + T · 也可从右键菜单开始。Chrome 内置页、商店、PDF、iframe 与封闭 Shadow DOM 暂不支持。
